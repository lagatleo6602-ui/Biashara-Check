    Add an admin

    Generate a one-time code and give it to the new admin in person or by phone. On the login page they choose Create account, then Study admin, and enter it. A code works once and expires after 24 hours. Generating a new one cancels the old one.

    Hand over super admin

    There is one super admin. Hand the role over before you leave the study. You'll stay an admin but can no longer add admins.
